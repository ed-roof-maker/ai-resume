## AI Schizophrenia Deep Research Demystifier
🚀 I built an AI schizophrenia expert chatbot.

Firstly, I built an AI debater that inputs a claim, then debates it, for and against. I then used this tool to generate 40+ knowledge articles about schizophrenia. Examples of debated claims are; schizophrenics are dangerous people, there are plenty of supports for schizophrenia in Australia etc.

These predebated AI knowledge articles, form the bedrock of my schizophrenia demystifier chatbot.

I then created an agentic RAG agent that searches a vector database filled with the predebated knowledge articles. These were loaded from markdown files, and then chunked in a heading aware way.

Once the agent was working in my jupyter notebook, I created the gradio user interface.

After several rounds of testing, I realized I needed stronger guardrails.

An example runtime prompt guardrail is; via regex, check for message patterns that allude to the user wanting to stop their medication. Once that guardrail is activated, send a medical disclaimer message.

Overall, I learnt how to implement agentic RAG, and productionize it with guardrails, fit for a publicly facing live demo.

🚀 A live productionized demo of my expert chatbot is here - https://edmonddendekker.com/schizophrenia

🖥️ Code is here - https://github.com/ed-roof-maker/ai-resume
