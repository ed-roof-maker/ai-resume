## Cognitive Behavioural Therapy (CBT) Practitioner Course (Udemy)
I did a CBT course at the Caboolture Hospital, but i wanted to own a Udemy online course that i could revise and to also get another perspective. The key takeaway is the ability to think logically instead of making assumptions. An important tool especially if you are under psychosis.

## Learning Path: SELinux: Master SELinux System Administration (Udemy)
I learnt how SELinux works within a Linux operating system. I learnt how to tune an OS with SEBooleans to enable applications work within a specific context. I learnt how to use audit2allow to generate a custom policy so that one can see what booleans need enabled, or whether to keep the custom module and load it.

## Linux Security and Hardening, The Practical Security Guide (Udemy)
I learnt about MAC and DAC, mandatory access control and discretionary access control. I learnt how to harden SSH. I learnt how to tune the kernel. I learnt about security auditing tools that identify security gaps and allow further hardening.
